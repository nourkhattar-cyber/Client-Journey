Inquiry & Availability Check

Start with the named maid, try alternatives twice, then collect requirements only if needed.

Original maid stays in the flow and moves directly to Stage 2.

  4. Send matching profiles

  6. If no match - choose CC Service or continue matching / lost lead

Stage 8

Resolution Flow

When the trial fails, the team first tries to retain the client with replacement or supervisor intervention.
