Stage 1 - Client Inquiry (chat-based revision)

This revised Stage 1 is based on the actual conversations you shared. It shows the intake journey from a client asking about a Peekaboo maid through MMR triage, early fit validation, alternatives, and the first Sales/Bot handoff. The red notes highlight where clients stalled, where the wrong response was triggered, and where mismatches should have been caught before a package or script was sent.

Repeated evidence folded into this stage: delayed first response, ignored contact or call requests, repeated requirement collection, duplicate package messages, profile mismatch found too late, and weak handoff ownership.

S1-01 Delay / wrong first response
  • 13h to 21h delays before the first answer
  • Client sends "?" or "I am still waiting"
  • Contact or call request answered with a sales script instead of the actual answer
S1-02 Fit not checked before package
  • Dogs, cooking, toddler/newborn care, age, live-in/live-out discovered too late
  • Wrong maid brief used or not read at all
  • Should have been caught before sales handoff
S1-03 Repeated requirement capture
  • Client gives requirements to MMR, then Sales/Bot asks again from scratch
  • Existing clients treated as new prospects
  • No single owner across teams
S1-04 Handoff failure: MMR to Sales/Bot
  • Duplicate package sent twice by two agents
  • Salary or refund terms communicated inconsistently
  • Bot jumps in without reading the prior thread
S1-05 Inventory gap / bad alternative handling
  • No matching shortlist, or only generic website links sent
  • No escalation when inventory is exhausted
  • Client left to browse alone instead of receiving curated substitutes
S1-06 Call request ignored
  • Client asks: "Can someone call me?"
  • Team replies with text or package instead
  • No human call at the highest-intent moment
S1-07 Start date / legal sequencing missed
  • Client not ready within 7 days should be routed to follow-up, not pushed to buy now
  • Existing contract or old-maid cancellation should be clarified before the new trial starts
  • Budget issue should trigger cheaper profiles, then monthly plan
